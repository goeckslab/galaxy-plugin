# Galaxy logo

`galaxy-directory.png` and `galaxy-logo.png` are the same 256 × 256 icon: the symbol of the [official Galaxy logo](https://artifact.galaxyproject.org/images/galaxy-logos/galaxy_project_logo_square.png), without the wordmark, on a white square. It matches the icon the Galaxy MCP service and its cards show, and is small enough for ChatGPT's personal connection icon upload. Logo design: Petr Kadlec. The symbol identifies the Galaxy Project and its platform; this plugin is published by the Galaxy Project.

The logo is not relicensed by this package. See the [Galaxy branding usage conditions](https://artifact.galaxyproject.org/images/galaxy-logos/).
