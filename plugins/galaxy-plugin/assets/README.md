# Galaxy logo

`galaxy-directory.png` is the 256 × 256 directory rendition of the [official Galaxy logo](https://artifact.galaxyproject.org/images/galaxy-logos/galaxy_project_logo_square.png). Logo design: Petr Kadlec. The symbol identifies the Galaxy Project and its platform; this plugin's publisher is JUNHAO QIU.

The logo is not relicensed by this package. See the [Galaxy branding usage conditions](https://artifact.galaxyproject.org/images/galaxy-logos/).
